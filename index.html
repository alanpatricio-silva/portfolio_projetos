Projetos de Análise de Dados

Análise de Dados do Airbnb em Nova York (2011–2019)

Este projeto teve como objetivo desenvolver uma análise crítica de dados do Airbnb sobre o mercado de locação de quartos na cidade de Nova York. O projeto teve como objetivo desenvolver um relatório no Power BI composto por dois dashboards interativos, com análises gráficas e detalhamento dos dados em tabelas e matrizes. Os dados utilizados são provenientes do conjunto de dados do Airbnb, que inclui informações de 2011 a 2019 para a cidade de Nova York.
